# Security reports

This monitor provides evidence and assessments. It does not enforce a sandbox or block agent actions. Model confidence is self-reported; redaction and capture coverage are imperfect.

Do not post credentials or real transcripts in public issues. Report vulnerabilities through the repository's private security reporting feature when enabled. If it is unavailable, use a private channel with the maintainer before disclosing details publicly. A report should include a minimal synthetic reproduction, affected version and expected versus observed behavior.

The initial 0.1 release is experimental. There is no promised response SLA. Keep the dashboard on localhost and inspect evidence before sharing it. Install hooks only for agents you intend to monitor, and preserve the settings backups for rollback.
